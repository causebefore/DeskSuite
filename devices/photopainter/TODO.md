# PhotoPainter 后续事项

## 当前基线

以下主线功能已经完成，不再作为待办：

- 服务端多页面 Manifest 与设备端 PPF2 四灰阶传输。
- 最多 16 页集合下载、SD 持久化、A/B 状态恢复和原子提交。
- 左右按键循环切换照片，确认键长按进入深睡。
- 墨水屏刷新期间暂停按键处理，刷新完成后恢复。
- 确认键唤醒与内部定时器唤醒。
- 冷启动或确认键唤醒后保持 3 分钟，无操作再进入深睡。
- 定时唤醒后同步集合，并按照服务端周期重新休眠。
- 普通同步失败时使用 1/5/15 分钟跨深睡退避，继续失败时按可信 RTC 对齐下一本地整点；
  RTC 时间不可信时退回相对 60 分钟。

## P0：下一步优先完成

- [ ] 深睡唤醒时不强制执行全屏刷新：
  - 优先采用 NVS 保存最后一次成功显示的 `page_id`、`content_version` 和状态结构版本。
  - 这份状态同时作为后续局部刷新重建“面板当前旧帧”的显示收据；不能仅根据 SD 中的活动集合推断物理屏幕当前页面。
  - 仅在成功完成物理刷新且页面或内容版本发生变化时写入 NVS，避免无意义写入。
  - 唤醒后读取活动集合并校验保存的页面；页面存在且 `content_version` 一致时，只恢复当前索引、按键和播放状态，不调用显示 Service。
  - 当前页内容变化、左右按键切换，或持久化状态缺失、损坏、版本不兼容时，才执行全屏刷新。
  - 全屏刷新失败时不更新 NVS，继续保留上一次确认显示成功的状态。
  - 备选方案是使用 RTC 内存保存相同字段；它不写 Flash，但断电或普通重启后状态可能丢失。
- [x] 收敛启动阶段的失败路径，避免 `app_main()` 返回后设备长期保持唤醒：
  - 已保存 Wi-Fi 配置但 AP 不可用时，前三次进入 1/5/15 分钟定时休眠重试，继续失败时
    按可信 RTC 对齐下一本地整点。
  - 内容刷新 Task 启动失败时，不允许电源 App 永久停留在 `WAIT_REFRESH`。
  - 无网络配置且正在显示配网二维码时保持唤醒 5 分钟，等待用户配置。
  - 系统、关键通信、配网、照片/内容链路或电源管理失败统一进入 OTA 回滚或退避深睡。
  - 后端上下文和内容刷新初始化失败不再保留无法关网、无法自动休眠的半运行模式。
- [ ] 为关键协议和持久化事务补充自动化测试：
  - 使用固定四灰阶 PPF2 黄金样本验证服务端生成结果和设备端像素解析结果。
  - 覆盖 CRC32、文件 SHA-256、载荷 SHA-256、位深、尺寸和载荷长度错误。
  - 覆盖 10/16 页、HTTP 304、缓存复用和下载中断。
  - 覆盖 A/B 单槽损坏、临时文件残留、旧集合恢复和 SD 缺失。
  - 验证新集合只有在目标页面显示成功后才推进 `collection_generation`。
  - 验证 RTC 保留的 1/5/15 分钟短期退避、长期失败下一本地整点和时间不可信兜底计算。

## P1：稳定性与产品化

- [x] 接通 PCF8563、ESP 系统时间与网络校时：
  - 启动时使用 RTC 恢复系统时间。
  - 联网后使用 SNTP 校准系统时间，并回写 PCF8563。
  - 统一 UTC、本地时区和日志时间，消除 `70-01-01` 日志。
- [ ] 定义 SD 热插拔和运行期 I/O 故障恢复：
  - 下载或显示期间拔卡时中止当前事务并保留旧活动集合。
  - 重新挂载成功后主动触发一次内容刷新。
  - 明确连续挂载或 I/O 失败后的 LED、重试和休眠策略。
- [x] 为 `AUTO_SLEEP_BLOCKED` 定义有界恢复策略，避免显示、SD 或网络清理错误导致设备无限期保持唤醒：
  - 阻塞状态立即转换为 1/5/15 分钟短期退避或长期失败 RTC 整点计划，并再执行一次完整停机。
  - 完整停机再次失败后，最佳努力关闭蜂鸣器和 LED、重建唤醒源并进入保底 Deep-sleep。
  - 保底路径无法配置唤醒源时立即重启；固件写入中的 `INSTALLING` 状态不参与保底休眠。
- [ ] 明确 OTA 范围：
  - 如果近期需要 OTA，补齐 OTA Service、启动有效性确认、下载校验和回滚验收。
  - 如果暂不提供 OTA，删除文档、构建配置和残留 Manifest 解析器中的超前承诺。
