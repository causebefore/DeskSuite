# `app/workflows` 工作流编排层

本目录放置跨多个服务、需要明确数据流和状态边界的业务编排。外部数据访问、
设备状态、日志和 OTA 等单一能力仍由 `app/services/` 提供，工作流只复用应用
启动时创建的服务实例，不自行重复创建连接或缓存。

## 工作流

- `assistant/`：文字与语音共用的 AI 对话、工具、短期会话和长期记忆编排。
- `voice/`：把设备音频接入 Assistant，再把回复转换为现有语音帧协议。
- `display/`：PhotoPainter 页面依赖、取数、渲染、四灰阶量化和 PPF2 发布。
- `dashboard/`：DeskMate 天气、日历、邮件和额度的确定性并发投影。

`display` 和 `dashboard` 不经过大模型，保证相同输入产生可预测的设备数据。
`assistant` 和 `voice` 分别维护独立的中文 README，说明模型、记忆和音频协议
边界。

## 目录规则

每个工作流目录必须包含中文 `README.md`，至少说明入口、输入输出、完整数据流、
状态归属、失败策略和本地测试方法。共享的数据源适配、缓存和外部 API 降级逻辑
不得复制到工作流目录。
